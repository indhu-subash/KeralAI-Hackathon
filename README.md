# 🌾 Kerala Commodity Price Intelligence System

A web-based platform that helps users **view, compare, and understand commodity prices across Kerala**.

The system provides current prices, historical price trends, district-wise comparisons, market insights, and price alerts in one place.

---

## 📌 Features

### 📊 Market Price Dashboard

Users can select:

- Commodity
- District
- Market

The dashboard displays:

- Current Price
- Minimum Price
- Maximum Price
- Average Price

---

### 📈 Historical Price Trends

Users can view how commodity prices have changed over time.

Features include:

- Daily price history
- Weekly price history
- Monthly price history
- Yearly price history
- Custom date range
- Line and bar charts
- Commodity-wise trends

---

### 🗺️ District-wise Comparison

Users can compare the price of a commodity between different districts in Kerala.

The system can show:

- Highest price
- Lowest price
- Average price
- Price difference between districts
- Market-wise comparison

---

### 🔔 Price Alerts

Users can set a target price for a commodity.

For example:

```text
Commodity: Coconut
Target Price: ₹9,000

Alert when price:
☑ Goes above ₹9,000
☑ Goes below ₹9,000
```

Users can save and manage their own price alerts.

---

### 💡 Market Insights

The system provides simple information about price changes.

Examples:

- 📈 Price is increasing
- 📉 Price is decreasing
- ➡️ Price is stable
- Highest-priced commodity
- Lowest-priced commodity
- Major price changes
- Important price trends

---

### 🔎 Search & Filters

Users can easily find the required information using:

- Commodity search
- District filter
- Market filter
- Date filter
- Price sorting

---

## 🗃️ Data

The system uses commodity price data containing information such as:

| Field | Description |
|---|---|
| Date | Date of the price |
| Commodity | Name of commodity |
| District | Kerala district |
| Market | Market name |
| Minimum Price | Minimum price |
| Maximum Price | Maximum price |
| Average Price | Average price |

The historical data allows the system to analyze **long-term price changes and trends**.

## 🎯 Purpose

The main purpose of this project is to make Kerala commodity price information:

- Easy to access
- Easy to understand
- Easy to compare
- Useful for decision-making

The system can be useful for **farmers, traders, consumers, students, and researchers**.
